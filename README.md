# Password Strength Checker

A simple Python program built for my Applications of ICT assignment. It checks how strong a password is based on length, numbers, upper/lowercase letters, and special characters.

## How It Works
- Prompts the user to enter a password.
- Evaluates the password against 5 security rules.
- Gives a score out of 5 along with feedback on how to make it stronger.

## How to Run
```bash
python password_checker.py
